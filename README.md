# 🔥💧 Fireboy & Watergirl: Forest Temple on Spartan-7 FPGA 🌲🎮  

Welcome to our **Fireboy & Watergirl: Forest Temple** project! This is our **final project for UIUC's ECE385 Digital Systems Laboratory**.  

Our goal was to faithfully recreate the **first level** of the classic cooperative platformer game **Fireboy & Watergirl** on the **Spartan-7 FPGA** using **SystemVerilog**. We meticulously developed and integrated various modules, including:  
- 🎮 **Character movement**  
- 🔍 **Collision detection**  
- 🏗️ **Interactive environment elements**  
- 🎨 **Color mapping system**  

All of these components come together to deliver an engaging **two-player experience**.  

🎥 **Check out our video demonstration** to see the game in action!  

---

## ⚙️ Project Requirements  

To successfully run this project, you will need:  

- 🖥️ **Spartan-7 Urbana FPGA Board**  
- ⌨️ **Basic USB Keyboard** (for player controls)  
- 🛠️ **Vivado** (for FPGA programming)  
- 🔧 **Xilinx** (for C code development)
